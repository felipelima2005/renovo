# 🅿️ Renovo — Rede de Estacionamentos

> Website institucional da **Renovo**, uma rede de estacionamentos moderna e confiável. Projeto atualmente em fase de planejamento e desenvolvimento inicial.

---

## 📋 Sobre o Projeto

O site da **Renovo** tem como objetivo apresentar a rede de estacionamentos ao público, oferecendo informações sobre unidades, serviços, planos e formas de contato. A proposta é criar uma experiência visual limpa, profissional e de fácil navegação para os clientes.

---

## 🚀 Tecnologias Utilizadas

| Tecnologia | Função |
|------------|--------|
| **HTML5** | Estrutura e semântica das páginas |
| **CSS3** | Estilização, layout e responsividade |
| **JavaScript** | Interatividade e comportamento das páginas |

---

## 🗂️ Estrutura de Pastas

```
renovo/
├── index.html          # Página principal
├── css/
│   ├── style.css       # Estilos globais
│   └── responsive.css  # Media queries
├── js/
│   └── main.js         # Scripts principais
├── assets/
│   ├── images/         # Imagens e ícones
│   └── fonts/          # Fontes customizadas
└── pages/
    ├── unidades.html   # Página de unidades
    ├── servicos.html   # Página de serviços
    └── contato.html    # Página de contato
```

## ⚙️ Como Rodar Localmente

Por ser um projeto puramente frontend, não há necessidade de instalação. Basta:

1. Clonar o repositório:
   ```bash
   git clone https://github.com/felipelima2005/renovo.git
   ```
2. Abrir o arquivo `index.html` diretamente no navegador, **ou** usar uma extensão como o [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) no VS Code para uma experiência melhor.
